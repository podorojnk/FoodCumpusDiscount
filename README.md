# FoodCampus — DiscountModule

Практическое задание: реализация программного модуля по User Story и архитектуре.

**User Story:** Как студент-льготник, я хочу подтвердить студбилет для получения скидки 15%.

| Файл | Назначение |
| --- | --- |
| `discount_service.py` | Код модуля `DiscountModule` + заглушка `StudentRegistryStub` |
| `test_runner.py` | Test Driver: позитивные и негативные сценарии |
| `README.md` | Описание и Bug Report |

## Спецификация

- **Вход:** `card_id` — строка из ровно 8 цифр (0–9), например `"12345678"`.
- **Выход:** `15.0` — билет найден в базе; `0.0` — билет корректен, но в базе не найден.
- **Ошибка:** неверный формат (не строка, пусто, буквы, пробелы, слишком длинная строка) → `InvalidCardError` с понятным сообщением.
- **Stub:** внешняя база студентов заменена заглушкой `StudentRegistryStub` (фиксированный список билетов).

## Запуск

```bash
python test_runner.py
```


## Bug Report

Баги найдены стресс-тестом на первой (черновой) версии модуля, где номер приводился через `int(card_id)`. Все баги исправлены в `discount_service.py` (проверка формата через регулярное выражение до обращения к базе).

| ID | Модуль и метод | Входные данные | Ожидаемый результат | Фактический результат | Статус |
| --- | --- | --- | --- | --- | --- |
| BUG-01 | DiscountModule.apply_student_discount | `"ABC-123"` (текст вместо цифр) | Сообщение о неверном формате | Программа упала: `ValueError: invalid literal for int()` | Исправлен |
| BUG-02 | DiscountModule.apply_student_discount | `None` | Сообщение о неверном типе данных | Программа упала: `TypeError: int() argument must be a string...` | Исправлен |
| BUG-03 | DiscountModule.apply_student_discount | `"00123456"` (действующий билет с ведущими нулями) | Скидка 15.0 | Скидка 0.0 (нули отброшены при `int()`, билет «не найден») | Исправлен |
| BUG-04 | DiscountModule.apply_student_discount | `" 12345678 "` (пробелы по краям) | Ошибка формата | Скидка 15.0 (пробелы молча проигнорированы) | Исправлен |
| BUG-05 | DiscountModule.apply_student_discount | `"１２３４５６７８"` (юникод-цифры) | Ошибка формата | Скидка 15.0 (юникод-цифры принимаются как обычные) | Исправлен |
| BUG-06 | DiscountModule.apply_student_discount | Строка из 5000 цифр | Сообщение «слишком длинный номер» | Программа упала: `ValueError: Exceeds the limit (4300 digits)` | Исправлен |
